# Takeroom Studio

A music studio that runs in the browser. One file, nothing to install.

## Features

- **Recording**: count-in, every take kept, and one-click **Clean up take** (removes rumble, gates background noise, levels volume, trims silence).
- **Editing**: move, trim, split, duplicate and delete clips, with snap to grid and 150 steps of undo.
- **Beat maker**: 16-step drum grid with style presets, swing, per-sound volume, beat on/off per bar, and sampling from your own files or recorded clips.
- **Mixing**: per-track volume, mute, solo, pan, low-cut, dynamics and reverb.
- **Reliability**: autosaves every change in your browser.
- **Export**: renders the song to a WAV file.

## Use it

Open `index.html` in Chrome, Edge or Safari. Allow microphone access when you press Record.

## Shortcuts

| Key | Action |
| --- | --- |
| Space | Play or stop |
| R | Record or stop recording |
| S | Split selected clip at the playhead |
| Delete | Delete selected clip |
| Ctrl/⌘ D | Duplicate selected clip |
| Ctrl/⌘ Z | Undo (Shift for redo) |
| Home | Back to the start |
